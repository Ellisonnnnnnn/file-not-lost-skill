同一个任务（AR 综合良率 · 未来两周 / 14 天 / demo-1）在四种结构下的呈现，四版都用真实数值。

当前抽屉的六个问题
  1. 标题说两遍：抽屉头「AR 综合良率 · 未来两周」下面，正文又起一个 h2「AR 综合良率 · 全部产品」。
  2. 导出入口两处：头部「导出数据」下拉 + 底部「导出 CSV / 导出完整 JSON」。
  3. 元信息散成四行：任务号 / 版本 / 步骤、历史与预测范围、数据口径快照、数据划分，各占一行小字，读起来像备案文件。
  4. 指标卡有一个是过程量：预测均值 / MAE / RMSE / 有效日样本，「有效日样本」不参与业务判断，却占了一格的视觉权重。
  5. 解读区 200 多字挤在一屏：① ② ③ 三段正文句式相近，「如何判断是否可用」又在复述上面的 MAE。
  6. 结尾免责说三次：「解读依据当前数值…」「结果可追溯到样本…」＋ 图表上方 3 行「怎么看这张图」。
本次补齐 · 四版一致，对齐主稿「结果与建议」抽屉的全部功能
  1. 结果版本切换：头部 结果 v1 / v2 / v3 下拉。
  2. 图表显示开关：趋势图与验证对比图可整块隐藏。
  3. 字段与划分快照：目标列 YIELD_RATE、特征列 3 项、训练 83 / 验证 17 / 测试 19。
  4. 数据划分与交叉验证：划分色条、三段区间、验证 / 测试 MAE、3 折折表。
  5. 验证数据：测试集实际 vs 预测对比图、19 条明细、样本内覆盖率 100%。
  6. 模型对比与评估环节表：4 个候选、1-SE 简约选型说明。
  7. 口径与字段：数据源、表、字段、口径、范围、划分、目标 / 特征列、补充要求。
  8. 导出与下一步：导出 CSV / 完整 JSON；查看验证明细、检查数据与口径、改为 7 天重新确认。

数值统一为主稿当前实际产出：119 天有效样本（83 + 17 + 19）、测试 MAE 0.16。此前页面上的 133 天 / 63-14-28 / 0.17 是旧夹具，与划分对不上（63+14+28=105≠133），已一并校正。

建议

以 方案 A 打底：一屏内给结论、图和 5 行明细，标题与导出各留一处；若业务方明确要「先读判断再决定看哪里」，选 方案 B，摘要把三条要点写成人话。

C 适合后续还要往抽屉里加内容（异常检测、版本对比）；D 适合完全不想读图、只想拿结论去开会的人。
