核对数据与字段 · 信息重排方案

同一份数据（11 列 / 119 条 / 预览 50 条）在四种布局下的样子。四个方案共用同一份勾选状态，切换 tab 可直接对比；表头、字段卡、下一步都可以点。

现在「乱」在哪 —— 五处重复与堆叠
  1. 标题说三遍：抽屉头「核对数据与字段」→ 内容区大标题「先核对数据，再选择模型输入」→ 副行又说一遍数据源与范围。
  2. 提示与入口重复：「操作提示」整条灰底讲三段话，而「滑选特征列 / 切换目标列」两个按钮本身就是入口；图例列出 3 种角色，实际有 4 种。
  3. 表头一行塞四层：角色标签 + 字段名 + 中文名·类型 + 「可选为特征 / 保留为索引 / 设为目标 / 当前目标」，每列都重复。
  4. 表格底部四层：分页行 → 已选特征 chips → 数据集划分与验证 → footer 再报一次「目标 / 特征数」。
  5. 结论分散：「目标是什么、选了几个特征」在工具栏、chips 区、footer 各出现一次，没有唯一落点。
