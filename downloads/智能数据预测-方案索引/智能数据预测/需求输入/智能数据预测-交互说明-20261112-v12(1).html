开始预测

有数据、至少一个特征和一个目标，且数据划分配置有效时，点击“开始预测”即运行，并将字段配置冻结进本轮结果。移除“已核对数据”和“特征已可获取”两个勾选项，不再要求用户重复承诺。目标与特征互斥、无可用数据和缺少字段仍由系统校验；无效配置就近提示。预测时特征可用性属于数据与模型的校验责任，不能因为点击按钮就认定已完成因果验证或排除泄漏。

2.1 数据集划分与交叉验证

入口位于“核对数据与字段”页，紧接已选特征。默认按时间先后以 70% / 15% / 15% 分配训练、验证、测试，默认使用独立验证集；这些比例是原型的初始配置，不是平台准确率承诺或强制规范。

设置用户操作实际规则
按时间比例分别输入训练 / 验证 / 测试百分比均大于 0，合计 100%；训练和验证按日样本数向下取整，剩余分配测试。示例 119 天得到 83 / 17 / 19 天。
指定日期范围编辑三段各自的开始 / 结束日期起止包含边界，必须在全量有效样本范围内，按训练 → 验证 → 测试排序且不重叠。可留空档，显示未使用样本数。
全量样本口径查看日期、各段数量和色条采用当前数据源、目标、产品和时间筛选后的全量日度序列；同日多条文件记录先按已确认方式聚合。预览 10 / 20 / 50 条不改变划分。
时间序列交叉验证选择验证方式后输入折数、窗口、间隔支持 2–5 折，窗口 1–60 天，间隔 0–30 天；默认 3 折，窗口 min(预测天数,14)，间隔 0。训练窗口逐折扩展，验证窗口等长，范围都在指定训练集内。
恢复推荐点击恢复推荐回到 70 / 15 / 15、独立验证集；不修改特征、目标或历史结果。
保存 / 执行保存选择，或直接开始预测输入即保存草稿。开始预测时再次检查并冻结 partitionPlan，不增加额外勾选或弹窗。

三类数据的用途

训练集：学习参数；开启交叉验证时只在其内部滚动选择参数。独立验证集：比较候选方案或选型复核。测试集：最后一次性能核验，不参与交叉验证或按成绩反复选型。若团队希望将训练与验证合并为更大的调参区，应另行调整约定；本版三段含义在页面和快照中保持一致。

滚动验证规则与校验

设训练集有 N 天，K 折，每折 W 天，间隔 G 天。第 i 折（从 0 开始）的验证窗口从 N−K×W+i×W 开始；训练集从训练区间首日延伸到该窗口之前 G 天。每折只读取对应训练窗口的已知数据。训练集最少 14 天、验证和测试各至少 1 天；交叉验证首折训练最少 14 天，即 N ≥ 14+K×W+G。这是本原型的操作校验门槛，正式模型所需最少样本数应由后端返回。

非法日期、超出范围、重叠、比例和错误以及交叉验证样本不足都会在该区块就近提示并阻止运行。返回修改数据范围后，比例模式按新范围计算；自定义日期保留供用户调整，不能静默截断。不同来源、不同目标的无效日处理仍以数据核对阶段为准。

方法依据：scikit-learn TimeSeriesSplit 描述了按时间推进、训练窗口累积及 gap；时间序列交叉验证说明 解释了随机打乱时序数据可能影响泛化评估。本版只提供时间顺序划分，不引入随机 K 折。

结果与计算边界

结果中的数据范围、样本数、测试明细日期及各折定义来自冻结的 partitionPlan；交叉验证 MAE 显示各折均值 ± 总体标准差（不是置信区间），同时展示各折 MAE / RMSE。独立验证和最终测试分开呈现。

  • 平台来源：数据、候选模型与指标仍为确定性生成的原型样例。新功能落实了划分配置和结果关联，但未连接数据库、后端训练或真实交叉验证任务。
  • 上传 CSV：使用真实目标日度序列计算 7 天同期基线。每折的预测只使用该折训练期的已知值，冻结预测后再对比整段验证值；没有使用验证期实际值更新预测。
  • 文件独立验证 / 测试：独立验证基于训练集；最终测试基于已选训练 + 验证数据，整段测试实际值只用于算误差。测试指标冻结后，未来预测可用已选训练、验证、测试的已知历史更新同期基线。日期空档不补造记录，星期模式取所选历史中最近已知值。
  • 参考区间：从各评估窗口之前的训练同期残差估计，按预测周数扩宽；未作概率校准。模型未进行多变量训练，所选特征仍仅保存为配置。

后端新增契约

请求同时保存 dataSplit（用户设置）与 partitionPlan（最终划分），后端用 datasetRevision 对应全量数据重新验证日期、样本量和行标识，不能信任前端计数。partitionPlan 包含 universe、train、validation、test、unused、method、cv.folds[]、cv.window、cv.gap、order 和 frozenAt。响应返回独立验证 / 测试明细、逐折预测与 MAE / RMSE、指标汇总和真实执行状态。

正式流水线中缺失值处理、标准化、特征选择等预处理必须分别在各折训练子集上拟合，不能先对全量数据拟合再划分；跨边界标签窗口、标签成熟时间和生产数据延迟需要服务端检查并设置相应间隔。前端日期划分不能代替这些检查。

3. 统一底部对话，修改当前条件

消息区分：用户在右侧，AI 在左侧，通过方向、头像、名称和气泡底色同时区分，不依赖颜色一种线索。附件引用跟随其所属用户消息；AI 的条件卡和结果卡保持白色内容区。默认定位保留本轮对话身份，不再直接跳到卡片顶端而隐藏发言人。长卡片继续在对话区滚动查看，底部输入不跟随滚动。

发起页、条件确认页、结果页使用同一个底部输入组件。对话与结果内容在上方独立滚动；确认卡中仅保留字段和“保存待确认 / 确认并预览数据”操作。用户直接在底部输入“预测改为 7 天，区间改为 95%”或补充分析要求，再点击“发送”或按 Enter；Shift + Enter 换行。快捷建议只填入，不自动发送。发送修改后重新整理条件，核对数据后再生成新结果；历史结果不覆盖。空输入和无效参数在底部就近提示，保留原条件和输入内容。运行中输入与发送禁用，但位置保持不变。

4. 输出、版本与异常恢复

结果继续展示趋势、参考范围、MAE / RMSE、验证明细、解读和下一步建议；新增已确认的目标列、特征列表及补充要求。历史版本保留当时的来源、字段、条件和结果快照。新指令或目标切换不覆盖旧结果。

JSON 导出包含完整 modelingSelection、字段映射、修订要求及结果。CSV 的预测 / 验证行增加目标列、特征列、补充要求及来源 / 版本信息；可能被电子表格解释为公式的文本继续转义。

从核对页返回可继续改条件。读取期间返回会使当前读取标识失效，迟到完成不会把用户带回旧核对页。选目标的异步文件读取也核对当前任务、页面与请求标识。任务暂停、重试和刷新继续保留已有版本；重试仍经过数据核对。

5. TXT / CSV 上传与引用

沿用 v8：支持 UTF-8 TXT / CSV，每份 2 MB、每任务最多 3 份；表格最多 50,000 行、100 列。文件预览、用途选择、引用勾选、同名检查、格式检查、无效行处理、示例下载及 IndexedDB 本机保存保留。

CSV 或表格型 TXT 可作数值数据，纯文本 TXT 可作字段 / 业务元数据说明。每轮仅一份表格作分析数据，其他附件可作背景。文件引用不自动提交，说明文字不是系统指令，也不能直接执行 SQL 或代码。已经被历史对话引用的文件保留供回看。

文件确认页仍允许修改日期、数值、产品、单位、百分比格式和汇总方式；切换目标后新增“数值（无单位）”选项。无效行需要用户确认排除，缺失日期不会自动补齐。文件基线至少需要 28 天连续有效历史；平台路径至少 78 天。

数据源维护与识别说明

数据源列表→连接 / 选表→AI识别→人工修正→确认发布

入口与列表

位于“AI资产管理 / 数据源管理”，独立于预测任务。按名称 / 数据库和状态查询；提供新建、维护、启用 / 停用与删除。列表展示数据库类型、库名、连接状态、表数量、口径状态和发布版本。预置一个已发布数据源和一个待识别数据源。

连接与数据表

新建、维护连接使用右侧抽屉。可编辑名称、ClickHouse 服务地址、端口、数据库、访问凭证引用、用途说明和接入表。至少选一张表；必填、数据库名和端口范围均校验。测试当前配置通过后才能保存。只读查询权限为演示约束，凭证用引用名表示，不输入数据库密码。

原型表清单为 AR / BR 两张预置表。正式环境应在连接成功后拉取真实元数据。地址含 fail 可触发模拟连接失败。连接身份或表范围改变后，原口径暂不可用于新预测，必须重新识别、修正并发布；历史版本保留。

发布校验

  • 数据源总体说明、字段业务含义、指标名称、合格等级及时间粒度不得为空。良率模板必须有不良等级。
  • 合格与不良等级不能重叠；等级用 | 分隔，不允许空项。A,T,Q 在当前源码样例中是一个完整枚举，不能按逗号误拆。
  • 指标所用字段必须存在于来源表，并与字段用途一致；数量映射必须对应数值类型。指标来源表必须在当前接入范围内。
  • 发布前必须填写说明并勾选“已确认字段映射、指标公式及等级取值”。成功后生成不可变版本，启用数据源供预测选择。

版本与预测联动

未发布的修改始终保存为草稿，预测继续使用已发布版本。确认卡选择来源时绑定 sourceId、version 和 definition 快照；切换到新版本必须显式选择。历史结果不随数据源后续修改变化。CSV 记录来源与版本，JSON 保存完整识别说明及结构化规则。

停用后阻止发起新预测，历史结果仍可查看。被任务或结果引用的数据源不能删除，可停用；未引用的数据源在二次确认后可删除。取消识别不会在稍后写入识别结果。

草稿保存与降级

旧提示的含义是浏览器无法写入本地草稿，不是数据源连接或预测计算报错。具体异常可能由存储策略或容量限制等引起，截图本身不能确定原因。v10 在任务输入过程中不弹出保存失败消息，按 localStorage → sessionStorage → 当前页面内存降级。读取时优先恢复本次会话中的新草稿；本地存储恢复可用后写入本地并清理对应会话副本，不清空其他数据。只有降级时才显示“会话草稿”或“仅当前页面保留”。后者刷新或关闭后不保留；点手动保存也不会误报成功。数据源资产模块未在本次调整范围内。生产版本的持久化应由后端实现。
