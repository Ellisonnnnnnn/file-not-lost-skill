文件模块 · UI 与交互优化

一条原则：最新版本做视觉主语，旧版本退为可追溯的次级线索。单版本模块不出现任何版本区块。以下四套方案用同一批真实文件与截图渲染，切换查看。

最新版与旧版权重相同2×2 网格里最新只是四格之一，扫不出哪份是当前
收起态只有图没有版本号 / 日期 / 状态，必须展开才知道
单文件也套 2×21 张图配 3 个虚线空位，视觉空洞
同一区域两种点击行为点图打开、点空白展开，容易误触
方案

方案 A画廊 —— 大图做主图，旧版压成胶片条

最新版以 16:10 大图独占卡片上部，左上角角标标注「当前 · vN」。旧版在底部排成一条 58px 高的胶片，灰度弱化、悬停还原。卡片全部等高：底部栏统一 62px，单版本时这一栏转为文件信息（格式 / 日期 / 大小 / 打开），既不出生版本区块，也不留空位。

最新版视觉权重 高旧版可读性 低卡片全部等高双列排布

方案 B行式 —— 主图 + 版本记录表

左侧固定 288px 主图，右侧是完整信息：模块名、当前版本高亮块、一行说明，下方「版本记录」表逐行列出全部版本（版本号 / 名称 / 状态 / 日期 / 大小），当前行蓝底高亮。单版本时整张表不出现，右侧只剩标题 + 说明 + 打开按钮。

最新版视觉权重 高旧版可读性 高单版本退化 最自然

方案 C层叠 —— 最新在前，旧版压成纸片

最新版是唯一实体卡片，旧版变成后面两层错位的「纸片」，悬停时纸片微微上浮，暗示下面还有东西。点击「查看 N 个旧版本」向下展开列表。单版本时纸片层自动消失，只剩一张卡。

最新版视觉权重 最高旧版可读性 低单版本退化 略空

方案 D层叠 2 —— 旧版向上扇形展开 + 蒙层聚焦

收起态与 C 一致：最新版是唯一实体卡，旧版压成后面两层错位纸片。点击卡片本身或上方的纸片区后，页面其余部分压暗并轻微模糊，卡片原地不动（上方空间不够时只向下让出最小距离）；旧版本从卡片顶端沿一条弧线向上扇形铺开——每张卡按弧线切线角度倾斜、错峰飞出，中间那张在最上层。悬停任一张上浮，点击直接打开对应文件。旧版超过 5 个时，末位替换为「+N 更早版本」入口卡，点开是全量版本清单，当前版高亮。悬停任一张历史版本，右上角浮出关闭钮，点击弹出二次确认（文件保留 7 天、到期自动清除）；确认后底部撤回条可逐个恢复。点蒙层、按 Esc 或再点卡片底部栏即收回原位。

最新版视觉权重 最高旧版沿弧线展开扇面 5 张，其余折叠删除需二次确认 · 保留 7 天蒙层聚焦

结论：A 画廊，本轮已按「卡片等高」优化

  1. 首屏扫视最快：7 张卡双列排布，大图即内容，1.6 屏看完所有模块，比行式少滚半屏。
  2. 卡片全部等高：底部栏固定 62px —— 有旧版时装胶片，无旧版时装「格式 · 日期 · 大小 · 打开文件」。同一行的高低差被彻底消掉，网格始终整齐。
  3. 旧版弱化的代价可接受：缩略图只给版本号，因为看旧版的第一诉求是「认出是哪一版」，认出后点开即可，不需要在这一层读全信息。

落地时：02 区 6 个模块与 01 主稿共用同一个卡片模板（主稿即「单版本」这一特例，底部自然走信息条），01 区现有的 21:9 横幅大图并入卡片后删除。

D 是在 C 的形态上换掉展开方式：纸片层叠不动，展开结果由「折叠列表」改为「旧版沿弧线向上扇形铺开 + 蒙层聚焦」。若最终选层叠，D 的展开可以直接替换 C 的列表，不需要改数据结构。
