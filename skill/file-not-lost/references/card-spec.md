# 卡片与浮层规格（层叠 2）

样式已固定在 `assets/index-template.html` 里，**不需要重写 CSS，也不允许改**。本文是让生成器知道「为什么这么排」，遇到窄屏、多版本、长名称时该怎么取舍。

## 卡片

```
┌─────────────────────────┐  ← .d-back.b2 / .b1  顶部两张纸片，仅多版本时出现
│ ┌─────────────────────┐ │     只露出 6px 与 12px 的顶边，暗示「下面还有」
│ │   16:10 主图        │ │  ← .hero  点它 = 打开文件
│ │   [当前 · v4]       │ │  ← .cap 角标
│ ├─────────────────────┤ │
│ │ 一句话说明，两行截断│ │  ← .d-sub
│ ├─────────────────────┤ │
│ │ 名称  [状态] 11-20·45 KB ↗ │  ← .d-bar  点它 = 展开扇形（多版本）
│ └─────────────────────┘ │
└─────────────────────────┘
```

- 栅格最小宽 320px：内容区 1032px 时三列，视口 ≤ 1128px 自动降两列，≤ 640px 单列
- 底栏是 flex：`名称(flex:1) + 状态 pill + 日期·体积 + 箭头`，gap 6、pill 内边距 6
- **名称超长会截断成省略号**，没有别的解法。所以 `name` 要控制在 12 字内，不能靠缩字号硬塞
- 无缩略图走 `.hero.plain`：文档轮廓图标 + `ext` 大字（11px），不要留空白格

## 交互分工

| 元素 | 多版本卡 | 单版本卡 |
| --- | --- | --- |
| 主图 `.hero` | 打开当前文件（`<a>`） | 打开文件 |
| 卡片其余任意位置 | 展开扇形 | 打开文件（整卡是 `<a>` 行为由底栏承担） |

点开卡片后，原卡 `.is-open` 时主卡 `opacity:0`，浮层里放一份克隆体——**克隆体只改 `transform`，不改布局**，否则会触发重排导致抖动。

## 扇形几何

以**纸片顶端中点**为圆心向下展开，不是从屏幕中心。

```
        ╭─── 弧线（R = max(760, half / sin26°)）───╮
       ╱   ╲                                  ╱   ╲
     v1     v2          v3                  v4     v5
   ────────────────── 实体卡（当前版）──────────────────
```

- 第 i 张的倾角 `θ = asin(offset / R)`，落点 `y = D − R·cosθ`，`D = R − lift`
- `lift = itemH/2 + 50`：扇形整体比卡片高一截，才能压在卡上方而不是盖住
- 相邻卡的中心距 = `(w[i-1] + w[i]) / 2 + gap`，其中 `w = itemW·cosθ + itemH·|sinθ|` 是**旋转后的包围盒宽**。不补偿的话端卡倾斜后投影变宽，会互相压盖
- 迭代 4 次收敛；实测缝隙稳定在 16–18px

## 容量：三级约束，取最小值

1. `FAN_MAX = 5`（硬上限，再多人眼就分不清了）
2. `capByWidth = floor(2·availHalf / (itemW + 34)) + 1`（左右可用宽能放几张）
3. 缝隙收到底仍越界 → `slots -= 1` 继续减

超出部分折叠成一张入口卡：`+N` + 「更多版本」，点开是全量清单浮层（`.dfan-sheet`，向上弹，上方空间不足 240px 时改向下）。

**结论**：可读区间是 3–5 张旧版。1440 宽、卡片在中间时能排 5 张；卡片贴右侧时只剩 3 槽——这是卡片位置决定的，不是 bug。

## 删除与撤回

1. 悬停扇形里的任一卡 → 右上角出现 20px 白色圆形关闭钮（`.dfan-x`），定位 `right:-8px; top:-8px`，约 8px 露在卡外
2. 点它 → 二次确认弹窗：标题「删除 v4？」，正文「文件将保留 7 天，期间可撤回，7 天后自动清除。」，按钮「取消 / 删除」（红 `#D54941`）
3. 确认后：卡片补位（其余卡重排）、底栏版本数递减、底部浮出撤回条「已删除 v4 · 保留 7 天 [撤回]」
4. 撤回是 **LIFO，一次一个**。删光后显示「历史版本已全部删除」

`removed` 数组只存在内存里，刷新即恢复——因为 7 天保留期是后端语义，静态页只演示交互。**接后端时补 `removedAt` 时间戳并过滤超期项**。

## 键盘与降级

- `Esc` 分层：先关确认弹窗，再按才收浮层
- 点蒙层关闭；`tab` 在弹窗两按钮间循环；初始焦点落在弹窗容器（避免鼠标点击出现蓝色焦点框）
- 弹窗关闭时硬重置状态，避免下次展开残留
- `prefers-reduced-motion` 下取消入场动画
- `@media (hover:none)` 下删除钮常显（触屏没有 hover）
- 打开浮层时 `html.dfan-lock` 锁滚动，并补偿滚动条宽度

## 可调参数

改这些不需要动结构，但**改完要重算指纹**（`build_map.py` 会拦）。

| 参数 | 现值 | 调大会怎样 |
| --- | --- | --- |
| `FAN_MAX` | 5 | 更挤，端卡倾斜过度 |
| `gap` 初值 | 18 | 更容易越界，触发减张 |
| 弧半径下限 | 760 | 弧线更平，像一字排开而不是扇形 |
| 错峰延迟 | 70ms | 入场更拖沓 |
| `itemW` 上限 | 148 | 卡片更宽，容量下降 |

## 不要做的事

- 不要给卡片加阴影层级区分——纸片层已经表达了层次
- 不要让扇形从屏幕中心弹出——原地展开是这套交互的核心
- 不要在底栏加第四个信息位（负责人、标签、进度）——会把名称挤成省略号
